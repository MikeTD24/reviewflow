# Démonstration vidéo

`reviewflow-demo.webm` montre le parcours automatisé réel : capture, enrichissement, sauvegarde, structuration en mode démo et exports.

Elle est générée depuis le scénario Playwright avec :

```cmd
npm run demo:video
```

Les enregistrements temporaires sont stockés dans `docs/video/recordings/` et ne sont pas versionnés. Seule la vidéo finale est publiée.
